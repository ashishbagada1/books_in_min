# books_in_min
A Node.js web app to discover books, read summaries, and find purchase links, built with EJS and Firebase. 📚🛒

**📚 Books In Minutes**

A fast and interactive web application designed to help users discover new books, read quick summaries, and easily purchase them online. Users can search for their favorite titles, explore author details, and get instantly redirected to e-commerce platforms like Amazon and Flipkart.

**✨ Key Features**
* **Book Discovery:** Browse and search for books easily using a clean UI.
* **Detailed Insights:** View the author's name, cover images, and a quick summary.
* **Integrated Purchase Links:** Direct "Buy" buttons for Amazon and Flipkart.
* **Secure Access:** Admin login and secure routes powered by Firebase Admin SDK.

**🛠️ Tech Stack**
* **Backend:** Node.js, Express.js
* **Frontend:** EJS (Embedded JavaScript), Vanilla JS, CSS
* **Database/Auth:** Firebase
* **Deployment:** Configured for Vercel

**🚀 How to Run this Project Locally**
1. Clone this repository to your local machine.
2. Open your terminal in the project folder and run `npm install`.
3. Create a `.env` file and add your environment variables.
4. Add your Firebase service account key JSON file to the root directory (ensure it is listed in your `.gitignore`!).
5. Start the server by running `node app.js`.
6. Open your browser and navigate to `http://localhost:3000`.
